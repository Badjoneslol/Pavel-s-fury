# Pavel's Fury : version Android

Le jeu est dans `www/index.html`. L'APK est construit automatiquement par GitHub.

1. Crée un dépôt vide sur github.com (ex. `pavels-fury`).
2. Envoie-y tous les fichiers de ce dossier (bouton « Add file > Upload files », y compris le dossier `.github`).
3. Va dans l'onglet **Actions** : la compilation démarre seule (3 à 5 minutes).
4. Va dans **Releases** : télécharge `pavels-fury.apk` depuis ton téléphone.
5. Ouvre le fichier, autorise « Installer des applis inconnues » pour ton navigateur, et installe.

Pour une nouvelle version : remplace `www/index.html` et renvoie-le. Un nouvel APK est créé.
Ta sauvegarde reste sur le téléphone tant que tu ne désinstalles pas l'appli.
